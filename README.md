# The Scoop — Cinematic Nine-Section Site

Open index.html with VS Code Live Server. No npm or database needed.

## Behavior
The journey and cone showcase are scroll-scrubbed via canvas image sequences. There is no scroll lock; reverse scroll reverses frame progression. Video previews in Signature Cones play the original uploaded MP4 files when tapped.

## Sections
1. Scoop Journey
2. Flavor introduction
3. Cone showcase (Blueberry, Strawberry, Chocolate)
4. Ingredient world
5. Creamy experience
6. Signature cones
7. Interactive flavor preview
8. Gallery moments
9. Finale

## Notes
All 16:9 footage is contained rather than cropped in the cinematic scroll scenes, with a dim blurred backdrop filling unused portrait space. Mobile playback quality depends on browser capabilities and asset loading. No source watermarks have been modified.
