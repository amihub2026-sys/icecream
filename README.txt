THE SCOOP — SCROLL-CONTROLLED MOBILE WEBSITE

Run: extract folder and open index.html with VS Code Live Server (or any HTTP static server).
No npm, no backend required.

HOW IT WORKS
- Vertical scrolling advances the actual footage frame-by-frame, in both directions.
- Journey: Chocolate -> Strawberry -> Blueberry.
- Flavor showcase: Blueberry -> Strawberry -> Chocolate.
- Full-screen sticky scenes scroll with the normal document; no wheel/touch hijacking and no autoplay lock.
- Frames are derived from six user-supplied videos. 18 fps/WebP optimizes file weight, though may look stepped on high-refresh devices.
- This is visual continuity, not a true 3D physical scoop traveling between different clips.
- Mobile keeps the full product in frame against a softly blurred same-frame backdrop.
- No AI watermark changes or concealment.

Note: A source video's baked watermark remains visible when present. The render quality is limited by source video resolution.
